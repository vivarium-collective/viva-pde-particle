Claim

B2b found that the native hybrid loses molecules at the curved membrane. Where does that show up in the field, and does the co-simulation have its own boundary artifact? Native fields are read on pyvcell's smoothed unstructured grid, so boundary elements sit near the true membrane rather than on the staircase.

Test

Same ball, grid, mesh and solvers as B2b. Conversion A_p → B_f (k = 0.5 /s, 20,000 A uniform in the ball), t = 2 s, 32 seeds per solver. - E[B] = A₀(1 − e^(−kt))/(V·N_A), with V each solver's own domain volume. - The interior is r < R/2. The outer shell is r > R − 2Δ = 3.5 µm. - Native values are volume-weighted on the smoothed cells; co-sim values are weighted by the lumped mass of the P1 DOFs.

Conclusion

Results (results/metrics.json, 2026-10-03; 32 seeds per solver; co-sim re-run with the B2d default membrane):

Geometry.

  • The node-centred smoothed cell domain is within −0.50% of the ball volume. Taken as-is, the pyvcell export is −8.4% (the tiling convention above).
  • Smoothing cuts the RMS radial error of the boundary surface from 0.108 to 0.065 µm.

Interior. Both solvers match the exact uniform E[B]: native +0.49%, co-sim −0.37%.

Next to the membrane.

  • Native:
    • The outer shell (r > 3.5 µm) is 2.3% below the interior (z = −20).
    • The profile declines smoothly from about r = 2.5 µm to 0.98 at the membrane: the diffusive footprint of the B sources dropped at the boundary.
    • This is B2b's exterior-binning loss, now localized.
  • Co-sim:
    • The shell is +0.12% (z = 1.2), unbiased.
    • The first run, with Smoldyn confined by the exact sphere, gave +1.3% (z = 10). This study attributed that to Pᵀ folding of exterior-node counts. Study B2d showed the cause was the domain mismatch instead: particles in the ~1.4% sliver between sphere and inscribed mesh load the boundary DOFs.
    • Confining Smoldyn by the mesh's own boundary (now the default) removes it.
  • Smoothing barely changes the native shell bias (−2.27% vs −2.29% on the staircase). The field is smooth on the scale of the boundary displacement (< 0.1 µm), so the smoothed grid helps geometry and visualization; the field artifact is in the coupling.

Neither effect is a limitation of VCell's geometry or PDE numerics. Both come from how particles near a curved membrane are binned to the field.

  • Native: VCellSmoldynOutput::computeHistogram (vcell-fvsolver, bridgeVCellSmoldyn/VCellSmoldynOutput.cpp:476–548) bins each molecule to the nearest node. Its correction for a nearest node in a different compartment (re-bin to the nearest same-compartment neighbour) is present but commented out. Re-enabling it is the likely native fix (virtualcell/vcell-fvsolver#25).
  • Co-sim fix (B2d, done): the mesh boundary as the particle membrane.
